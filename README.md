# React TO-DO App

Aplicación de gestión de tareas desarrollada con Next.js, React y TypeScript.

El proyecto consume una API REST de demostración para obtener y administrar tareas utilizando componentes reutilizables, hooks, peticiones asíncronas, manejo de estados y organización de una aplicación frontend.

## Funcionalidades

- La aplicación consume una API REST de demostración para obtener tareas y simular operaciones de creación, actualización y eliminación. Los cambios se gestionan localmente en el estado de la aplicación.
- Mostrar estados de carga.
- Manejar errores de conexión.
- Agregar nuevas tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Filtrar tareas por estado.
- Mostrar el número de tareas pendientes.
- Interfaz adaptable a diferentes pantallas.

## Tecnologías

- Next.js
- React
- TypeScript
- Tailwind CSS
- Fetch API
